
第一条命令输出与终稿表 7 相同单位、行次和精度的 Markdown 表。第二条同时写出 48 行未舍入的均值与样本标准差，复 RMSE 单位为 g，相对 L2 为无量纲比值，U MAE 单位为 g·cm。可通过 `--input PATH` 读取符合下述格式的重新推理结果。

## 条件和配对

M6 的标称不平衡量为 864.54 g·cm。200 个相关窗口源于一次降速。每个布局划分留出 21 种双点组合，包含 7 种涡轮机匣双点（TT）、7 种中介机匣双点（II）和 7 种跨机匣组合（TI）。在每个窗口和布局下，两个观测点的六个复通道及转速进入模型，复响应误差取其余 12 点的 36 个复通道。

S 表示在同一窗口转速和标称 U 下取得的 PCHIP 合成复响应，M 表示 M6 实测复响应。SS、SM、MS、MM 的第一个字母为观测输入，第二个字母为复响应目标。因此 SS 与 SM 使用完全相同的预测，MS 与 MM 也使用完全相同的预测。四种配对共用 M6 的标称 U、窗口、掩码与有效性条件。实测和合成响应须处于同一相位参考系。没有额外输入噪声。

## 输入文件和计算步骤

`group_sums.csv` 包含 360 行，用 `split_id, family, seed, scenario, pair_type` 唯一标识。每行汇总该划分中同一机匣组合类型下的 7 个布局和 200 个窗口。三个神经模型各有三个训练种子（42、43、44）。确定性反演的 seed 字段为空。

| 字段 | 定义 |
| --- | --- |
| complex_sse_g2 | 所有有效未观测复通道的复误差模平方之和（g²） |
| target_energy_g2 | 同一有效通道集合中目标复响应模平方之和（g²） |
| complex_count | 参与两项求和的有效复通道观测总数，实部与虚部合计为一个复观测 |
| u_abs_error_sum_g_cm | 共同有效的窗口与布局组合上 U 绝对误差之和（g·cm） |
| valid_cases | 参与 U 求和的窗口与布局组合数 |

每个预测有效案例要求两种输入均得到有效、有限的预测，两个输入点的三向测量均通过幅值和相位有效性检查。复通道还需满足未观测且其目标相位有效。本档案每一行均有 1,400 个有效案例和 50,400 个有效复通道观测。

1. 在每个分组内计算 `sqrt(complex_sse_g2 / complex_count)`、`sqrt(complex_sse_g2 / target_energy_g2)` 和 `u_abs_error_sum_g_cm / valid_cases`。
2. 在每个模型、配对、种子和划分内，对 TT、II 和 TI 的三项指标分别取等权算术平均。平方根在此步之前计算。
3. 在每个划分内平均三个训练种子的指标。确定性反演每个划分只有一组指标。
4. 对三个划分均值求算术平均和样本标准差（分母为 2）。论文显示的复 RMSE 乘以 1,000，相对 L2 乘以 100。误差条反映布局划分变化，窗口没有作为独立物理重复计数。

## 数值来源和交叉验证

分组和来自冻结 M6 评价归档中每个模型对应的逐窗误差分解文件，由 heldout_pairs 选出具体布局。四种配对分别累加 E_SS、E_SM、E_MS、E_MM；目标能量取 target_S 或 target_M；U 绝对误差取 abs_U_S 或 abs_U_M。仅分组和计数进入本 CSV。该文件可以重新计算表格的全部数字，逐窗重新推理则另需检查点与相应输入。

发布前将 SS、SM、MM 的未舍入结果与原实验的 `paired_summary.csv` 对照，将 MS 与补充评价的 `prediction_summary.csv` 对照。全部 48 组均值和标准差通过核对，按论文精度显示的 16 行、48 个单元格均与终稿表 7 相同。
