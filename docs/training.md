# 训练、布局与检查点选择

在仓库根目录运行。以 `--demo` 检查训练入口只需 NumPy 与 PyTorch。它在 CPU 上用解析函数生成 4 个训练 U、2 个验证 U 和 4 个转速，两组数据共享连续响应函数。程序依次试跑两个学习率，对三个候选 epoch 分别遍历 70 个已见掩码与四档噪声，输出 `selected.pt` 和 `selection.json`。示例只用于检验流程，输出目录应为新路径。

```bash
python -m training.run --demo --family gnn --split split0 --seed 43 --output demo-training
```

使用论文规模的预处理合成曲线，可按以下方式训练指定的网络与布局划分。默认使用 `cuda:0`；CPU 也可通过 `--device cpu` 运行。完整遍历所有验证布局的计算量很大，若只需检查论文的推理结果，可从随库分组统计量重算表 7；逐窗重新推理需自行在本地提供相应冻结检查点和输入。

```bash
python -m training.run --data-dir prepared --family gnn --split split0 --seed 43 --device cuda:0 --output training-split0-gnn-43
```

## 输入约定

`--data-dir` 接收 `train.npz` 和 `validation.npz`，均为按完整 U 曲线划分的开发集。合成复响应使用共同相位参考。下表列出每个归档的数据字段；代码按仓库的 `node_spec.py` 顺序解释所有输入。

| 字段 | 尺寸 | 单位与顺序 |
| --- | --- | --- |
| `response_g` | U 数 × 转速数 × 14 × 3 × 2 | 三方向转频峰值复加速度，g；末轴为实部、虚部 |
| `unbalance_g_cm` | U 数 | g·cm，训练与验证 U 数值集合互斥 |
| `rpm` | 转速数 | r/min，两文件共用同一递增网格 |
| `node_ids, angles_deg, casing_ids, directions` | 14、14、14、3 | 可选的轴顺序校验字段 |

程序对训练响应计算 2 个机匣 × 3 个方向的 RMS，逐机匣和方向汇集训练 U、转速和全部七个位置，对实、虚分量的平方和取均值后开方。若存在 `preprocessing.npz`，还将其中的 `scale_g` 与重算值比较。尺度在训练、验证和推理中固定。论文使用 1,000 个训练 U、200 个选模验证 U 和 599 个转速（3,005–5,995 r/min，间隔 5 r/min）。最终合成测试另外使用 200 个 U。M6 的实测输入、最终合成测试的 U 和各划分的 21 种留出布局均不用于这里的模型选择。

## 相同观测条件下的三个学习模型

每个模型读取转速、两处三向 1X 复加速度、位置、机匣标识和掩码。完整节点特征为 6 个归一化实虚分量、3 个幅值、1 个观测掩码、4 个几何特征和 1 个归一化转速。三者使用相同的样本、分割、损失和学习率搜索预算。GNN 的边属性由固定节点几何构建。

| 模型 | 网络结构 | 可训练参数 |
| --- | --- | ---: |
| GNN | 节点 15→128→128；三个四头边增强注意力块；节点响应头 128→64→6；全节点均值后以 128→64→1 预测 U | 435,739 |
| MLP | 展平 14×15；210→400→400→400→85，输出 84 个实数响应分量和 U | 439,285 |
| DeepSets | 共享编码 15→256→256，仅对观测节点平均；连接目标节点几何与转速后 261→512→256→6。U 头为 256→384→1 | 435,975 |

## 从训练到冻结

1. 三份 [布局清单](../training/pair_splits) 的下标从 0 开始，每份列出全部 91 种组合、70 种已见组合和 21 种未见组合。种子为 20261021、20261024、20261025。每个位置在已见和未见集合中分别出现 10 次和 3 次，21 种未见组合含 7 种 I–I、7 种 T–T、7 种 T–I。
2. 每个 epoch 打乱全部训练样本，每个样本随机取一个已见掩码及一档噪声。对观测通道施加 `z' = z + γ·s_cd·(ε_R + i ε_I)/√2`，其中两个实噪声分量来自标准正态，γ 为 0、0.01、0.03 或 0.05。计数器随机流绑定样本、物理通道、噪声档和种子，各模型使用相同实现；未观测输入置零，保留干净标签和转速。再从受扰观测通道中选最大幅值通道重新计算公共相位参考。
3. 训练目标为未测复数 MSE + 0.1 × 未测幅值 MSE + 0.1 × 已测复数 MSE + U MSE。响应误差使用六个训练 RMS 归一化；先在样本的各机匣和方向组内平均，再对非空组等权平均。U 误差除以 935.77 g·cm 后平方。模型选择分数只取未测复数 MSE 与 U MSE 之和。有限的全零观测内部预测也参与该选模分数；部署评分另使用有效性标志。
4. 每个主模型和划分先固定 seed 41 比较初始学习率 0.001、0.0003，单次最多 300 epoch。对 200 条验证曲线的 U/转速样本，固定一次平衡的已见掩码分配，遍历四档观测噪声；每五个 epoch 在这个固定集合上监控。按最佳监控分数选择学习率。各划分中三个主模型实际均选 0.001；各候选的成绩见 [hpo_results.json](../training/hpo_results.json)。
5. 以种子 42、43、44 使用同一选定学习率各做一次正式训练。每次最多 2,000 epoch；AdamW，权重衰减 0.0001，batch 1,024，梯度范数上限 1.0。连续 8 次验证未改善时 LR 乘以 0.5，下限 0.000001；连续 30 次未改善且距最近降 LR 至少 10 次验证时早停。CUDA 正向与反向使用原项目的 BF16 混合精度策略，损失按 FP32 计算；CPU 示范为 FP32。完整设置见 [config.json](../training/config.json)。
6. 每次正式训练保留监控分数最低的 3 个候选 epoch；冻结时以 FP32 对每个候选计算全部 70 个已见布局 × 200 个验证 U × 599 个转速 × 4 档噪声，共 33,544,000 个案例。比较逐例选模分数均值，平分取早期 epoch。Split0 的部署 GNN 为 seed 43、epoch 1830。表 7 对三个种子的指标分别计算，再在各划分内平均，最后报告三个划分均值的均值及样本标准差。

训练入口为可移植的单模型、单划分运行方式，保留原始批次生成、噪声、优化器、损失、监控、候选排序及完整验证规则。模拟运行会缩短训练和验证周期。重新训练的数值随设备和软件版本变化；论文报告值对应原研究选定的冻结检查点。
